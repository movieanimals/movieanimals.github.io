# Toth Movie Animals Website

This repository contains the website for Toth Movie Animals, a premier animal training service for film and TV productions. The site showcases the company's services and contact information with a cinematic design aesthetic.

## Repository Structure

- `index.html` - Main website (single-page, self-contained with inline CSS and JS)
- `site.webmanifest` - Web app manifest for mobile/PWA support
- `assets/img/` - Image assets and favicons
- `paw.png` - Logo image

## Features

- Cinematic design with film industry aesthetic
- Particle background animation
- Animated logo with shine effect
- Responsive layout for all device sizes
- Contact form via Formspree
- Social links (TikTok, IMDb)

## Development

The website is a single-page static site using vanilla HTML, CSS, and JavaScript. All styles and scripts are embedded in `index.html` for simplicity.

1. Clone this repository
2. Open `index.html` in your browser to view the site
3. Edit `index.html` for any changes

## Deployment

The site is hosted via GitHub Pages and deploys automatically on push to the main branch.
